This repository contains multiple Data Analyst projects built using SQL, Excel, Power BI, and Python. These projects demonstrate skills in data cleaning, dashboard creation, visualization, exploratory data analysis, and generating business insights using real-world datasets.

## Projects Included

### 1. Sales Analysis Dashboard (Excel + SQL)
- Created interactive sales dashboard using Excel.
- Analyzed sales performance across regions, products, and categories.
- Built KPI cards, Pivot Tables, charts, and slicers.
- Generated business insights from sales data.

### 2. Power BI Sales Dashboard
- Developed interactive Power BI dashboard with DAX measures and slicers.
- Visualized sales trends, category performance, and regional analysis.
- Created KPI metrics and dynamic reports for business analysis.

### 3. Python EDA Project
- Performed Exploratory Data Analysis using Python, Pandas, and Matplotlib.
- Cleaned datasets, handled missing values, and removed duplicates.
- Created visualizations and statistical summaries.
- Identified trends, correlations, and outliers in the data.

### 4. SQL Practice & Analysis
- Practiced SQL queries using joins, GROUP BY, subqueries, and aggregations.
- Performed sales and customer data analysis using SQL.
