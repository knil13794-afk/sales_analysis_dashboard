# Sales Analysis Dashboard

## Power BI Sales Dashboard

## Tools Used
- Power BI
- DAX
- Data Visualization
- Dashboarding

## Project Overview
This project analyzes sales performance across regions, products, and categories using Power BI dashboards and interactive visualizations.

## Key Insights
- Pune region generated highest sales
- Laptop was top-selling product
- Electronics category contributed highest revenue
- Sales performance improved during festive seasons
